# FAI-i450 CAD 坐标

本功能为 Flutter 原生桌面流程，不依赖 Microsoft Excel、HTA、WebView 或 AI 服务。

1. 导入 T100 BOM 和一份 SMT 站位表完成单表核对，或导入 SMT A、B 完成 A+B 核对。
2. 在“合并与导出”逐项确认 NG、已排除物料和候选料，生成 BOM 预览。单表模式只使用当前站位表；另一面未覆盖的 BOM 项需确认知悉，不补造坐标或 SMT 记录。
3. 打开“CAD 坐标”，导入原坐标 XLSX、UTF-8 CSV 或 TXT。
4. 选择原坐标单位 mm、mil 或 inch。仅当表头明确为 X/mm、Y/mm 时预选 mm，数值大小不用于猜测单位。
5. 生成 CAD 预览，查看坐标问题、源文件/工作表/一基行号及转换前后数值。
6. 输入文件名，导出单个 .xlsx。存在阻断问题时不能导出，原始文件受覆盖保护。

固定工作表名 Sheet1，固定十列：
PartType、RefDes、PartDecal、Pins、Layer、Orient.、X、Y、SMD、Glued。X/Y 为数值，显示四位小数，元数据字符串不会作为公式执行。

## 转换规则

先把所有有效原坐标转换到 mm，再计算完整原坐标的最小 Y 和最大 Y。孔、Mark 等未纳入输出的有效记录也参与范围计算，以保持旧 V1.6 工具兼容。

- Top：位置保持，角度规范化至 0–360°。
- Bottom：X 保持，Y = 最小 Y + 最大 Y − 原 Y，角度 = (原角度 + 180) mod 360。
- 按合并 BOM 位号顺序筛选；保留料号与 BOM、原坐标来源的关联。
- 该范围是坐标记录的极值，并不等于 PCB 外框或实际板高。

输出已预镜像，沿用旧工具约定，导入设备时 Bottom 不再重复启用“镜面”。本功能的样例兼容测试不能代替具体设备软件版本的实际导入与定位验证。

## 校验与失效

缺失/重复坐标、无效或非有限 X/Y/角度、无法识别面别、BOM 位号冲突、无效数量及数量与位号数不符均阻止导出。空坐标不会自动变成零。缺少角度列时沿用旧工具的 0° 默认值，并显示复核提示。

人工确认不会掩盖 CAD 数据错误。即使已确认将某项纳入合并，坐标校验仍需通过。无位号候选行不补造坐标，预览统计会显示跳过数量。

更换原文件、单位、核对规则、重新核对、撤销或更改人工确认都会使旧 CAD 预览失效。清空会丢弃导入中的迟到结果和未完成的保存请求。

## 开发验证

PowerShell 7：
~~~powershell
flutter analyze --no-pub
flutter test --no-pub
./tools/build-windows.ps1 -SkipChecks
~~~

~~~bash
./tools/build-linux.sh
~~~

自动测试涵盖底面 30° → 210°、全表镜像范围、明确单位、CSV 引号与换行、空值与零、重复和缺失、原文件保护、人工确认失效、异步清空及中英泰三语窄/宽窗口布局。
