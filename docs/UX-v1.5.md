# SMT-CHECK 1.5 桌面工作台

1.5.1：状态统一显示 PASS / NG；已排除物料和候选料也使用红色行底与各自状态标记，统计保持独立。浅色详情原因使用 #E00012，深色使用 #FF554A，并加粗显示。导航调整为工作台、AI、设置、帮助；设置内分“外观与 AI 接口”和“导入与规则”两项。

浅色为默认，黑色/蓝色/绿色主题、三语及非 Material 3 继续保留。

视觉重点放在工艺核对表格：一致标记 #0EDC61，异常标记 #FF3B30，使用深色文字保持对比度。浅色行底分别为 #8BF0AE 和 #FFAAA3；深色主题使用 #104A29 与 #621E1B。选中不覆盖红绿状态，只用中性单选标记、4px 侧线和加粗料号；底部显示当前料号。文件槽合为单一文件栏，统计采用上方标签和大号数字，筛选与搜索/导出分组排列。

AI 动画仅用于说明当前任务仍在运行。显示准备、等待确认、请求等待、模型分析、接收、完成/中断阶段；推理内容只触发阶段更新，不进入结果。计时每秒刷新，接收量来自真实接口内容，批次计数只在该批成功解析后增加，不伪造百分比。减弱动画启用时显示静态状态；取消、结束和离开页面时停止动画和计时器。

原文件结果使用严格的 `{"anomalies":[...]}` 清单，每条包含 part/category/reason/bom/smt/source 字符串。不发送供应商专属 response_format 参数；清单格式通过提示词约定。无效输出保持该批未完成并允许重试。只有全部批次成功且清单为空时才显示未发现异常。原文件、排除料和候选料仍完整进入核对，不因只展示异常而缩小发送范围。
