# SMT Fusion 1.13.0

- 应用显示名称改为 **SMT Fusion**，替换为 BOM → CAD / BlueEye FAI-i450 插画图标，去除外侧白色空白并保留透明圆角。
- 设置 → 关于与更新：在软件内下载更新，显示实际已下载大小及进度，支持取消、失败重试与 SHA-256 校验；不再跳转发布页。
- 校验成功后可安装更新。Windows 使用原有安装器原位升级并重启；Linux 使用系统授权安装 DEB；macOS 新增 PKG 供软件内安装，安装后可重启。
- 安装前再次校验本地文件，下载中断、大小不符、校验失败、安装授权取消或系统安装器不可用均有明确提示。运行中的核对、分析和导出任务完成前不能安装更新。
- 保留旧版的应用标识、安装路径、包名及兼容下载名称，旧版仍可发现此次更新。Windows/macOS 增加设置迁移，保留原有语言、主题、规则及接口配置。
- 原有 T100 BOM / SMT 核对、人工确认、A+B 合并、FAI450 生成、坐标差异检测和导入导出逻辑保持不变。

旧版需要先安装本次新版本，之后即可使用应用内更新。Windows/Linux 安装包仍保留 SMT-CHECK 文件名用于升级兼容，安装后显示 SMT Fusion。

下载对应平台的单文件安装包，无需解压：Windows x64/ARM64 Setup.exe，Linux amd64/ARM64 DEB，macOS Intel/Apple Silicon 通用 DMG 或 PKG。每个文件均附 SHA-256 校验文件。
