SMT-CHECK 1.10.1

- 修复“合并方式”标签浮出控件、与上方说明挤在一起的问题，改为控件内同行标签。
- 将合并文件名、Excel 导出按钮、命名提示和确认数量移到合并工作区顶部右侧，移除底部导出栏，为详情与预览表格提供更多空间。
- 文件名使用独立标签，修复浮动标签的边框显示问题。窄窗口及放大文字时自动换行；顶部内容过多时独立滚动，避免遮住表格或产生溢出。
- 保持逐项人工确认、预览与导出门禁、四列内容、BOM 文件名后缀和三语支持；调整窗口大小时保留已填写文件名与确认状态。
- 修正 macOS 安装检测对 Flutter 启动帧时间校正日志的误判；此类日志单独记录，并增加后续稳定运行检查，应用异常及其他引擎错误仍会导致检测失败。
- 提供 Windows x64 / ARM64 EXE、Linux amd64 / ARM64 DEB，以及 macOS Intel / Apple Silicon 通用 DMG 完整安装包和 SHA256。

Windows 安装程序未代码签名；macOS 为临时签名，未进行 Developer ID 签名或公证，首次启动可能需要在系统“隐私与安全性”允许打开。
