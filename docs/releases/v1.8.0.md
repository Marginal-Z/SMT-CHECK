SMT-CHECK 1.8.0

- NG 结果新增“查看具体差异”入口，详情按料号、品名 / 物料描述、数量、位号展示 BOM 与 SMT 原值及来源文件、工作表和行号。
- 描述不一致不再仅显示概括提示：结果与导出中列出两侧描述原文，详情用鲜红色突出变化片段，保留仅忽略大小写和空白的判断规则。
- 数量差异明确显示两侧汇总数量，以及 SMT 比 BOM 多或少多少；支持单站位表和 A+B 合并汇总。
- 位号差异逐项列出 SMT 缺少和多出的位号，并在原值对照中标红；相同位号对应不同料号时显示两侧料号和来源，不自动判定为等效或替代。
- 同一料号存在多种描述时说明冲突并列出原文；原始行问题补充 BOM / SMT、文件、工作表和行号，便于定位。切换详情记录时回到顶部。
- CSV 新增“字段差异”，JSON 新增结构化 `fieldDifferences`；保留原始数据及现有列，中英泰界面和导出同步更新。

提供 Windows x64 Setup.exe 和 Ubuntu / Debian x64 DEB 完整安装包。
