SMT-CHECK 1.11.1

- 新增原生“CAD 坐标”工作区：完成 T100-BOM 与单站位表或 A+B 核对、人工确认及 BOM 预览后，导入原坐标并生成 FAI-i450 十列 Excel。支持软件内预览、自定义文件名，不依赖 Microsoft Excel 或 AI。
- 优化 CAD 桌面布局：文件与单位集中在左侧，文件名与导出位于右侧；统一控件字号和高度，显示单表/A+B 模式及 BOM 就绪状态，将坐标转换说明收进可展开区域。中英泰三语、窄窗口和放大文字均覆盖验证。
- 单表模式保留 NG、已排除物料、候选料及仅 BOM 有记录项目的人工确认门槛，只整理当前 SMT 原始记录，不补造另一面的物料或坐标。
- 支持原坐标 XLSX、UTF-8 CSV/TXT，以及 mm、mil、inch 明确单位选择；兼容旧 V1.6 的全表 Y 范围镜像、Bottom 角度加 180° 规则。
- 缺失/重复坐标、位号冲突、空值、非有限坐标及数量不符会阻止导出。保留文件、工作表、一基行号及原字段追溯，保护原文件；修改来源、单位、规则或人工确认会使旧预览失效。
- 修复 WSL 挂载 Windows 目录时 DEB 打包权限不正确的问题。
- 提供 Windows x64 / ARM64 EXE、Linux amd64 / ARM64 DEB、macOS Intel / Apple Silicon 通用 DMG 及 SHA256。所有发布包须经过对应平台安装、启动和卸载检查。

用户真实样例生成 38 行，与正确坐标文件全部 380 个数据单元格一致。尚未进行 FAI-i450 设备实机导入验证；输出的 Bottom 已按旧工具约定预镜像，设备端不应重复镜像。

Windows 安装程序未代码签名；macOS 使用临时签名，未进行 Developer ID 签名或公证。
