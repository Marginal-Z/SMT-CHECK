# SMT-CHECK 1.12.0

新增独立坐标差异检测：按 RefDes、板号与层别关联，检测缺失、新增、重复、坐标、角度及属性差异。排序变化不产生元件 NG，默认坐标与角度比较容差均为 ±0.001，可在设置中修改。

新增 TP/FID/MH/NPTH 与用户规则、特殊特征统计、人工保留/排除和可追溯 JSON 报告。坐标系未确认时保持待确认，不推断原点或镜像。支持中英泰、搜索、筛选和详情。

补强 CAD 校验及 FAI450 导出回读，保留已有 Bottom 转换、十列格式与精度。真实样本对应 893 行生成数据与修改前十字段一致；446 个共有位号通过，TP10_1 保持缺失差异，118 项微小浮点差异归为容差内提示。

Windows x64/ARM64 提供单个 Setup.exe，Linux amd64/arm64 提供 DEB，macOS 提供 universal DMG。
