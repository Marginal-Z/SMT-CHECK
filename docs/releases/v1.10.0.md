SMT-CHECK 1.10.0

- 新增“合并与导出”桌面工作区：站位表 A / B 合并为 Excel，软件内预览，固定保留“料号、物料描述、数量、位号”四列。支持自定义文件名，自动以 `BOM.xlsx` 结尾。
- NG、已排除物料、候选料逐项人工确认是否纳入合并；全部确认后才能生成预览和导出。显示确认状态及时间，可撤销或修改决定，核对状态及统计保持独立。仅 BOM 有记录的异常需确认知悉，不补造 SMT 数据。
- 两种合并方式：料号与描述完全相同时汇总有效数量，或按 A / B 顺序保留每行明细。保留空值、不同描述、重复位号和来源，数量十进制精确累加，料号前导零不会丢失，原始文本不会作为公式执行。
- 更改文件、规则、核对模式或重新核对时，旧确认和预览失效；撤销确认立即锁定合并导出。清空时拦截尚未完成的保存任务。导出采用临时文件完成后再保存，禁止覆盖原文件。
- 新功能支持中文、英文、泰文，适配窄窗口和大屏桌面；默认浅色，沿用黑 / 蓝 / 绿主题色及 PASS / NG 高对比配色。
- 提供 Windows x64 / ARM64 EXE、Linux amd64 / ARM64 DEB，以及 macOS Intel / Apple Silicon 通用 DMG 完整安装包和 SHA256。

Windows 安装程序未代码签名；macOS 为临时签名，未进行 Developer ID 签名或公证，首次启动可能需要在系统“隐私与安全性”允许打开。
