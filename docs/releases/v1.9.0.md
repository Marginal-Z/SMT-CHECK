SMT-CHECK 1.9.0

- 非贴片关键词排除按料号覆盖 BOM / A+B 对应记录，自动进入“已排除物料”，不再留下误报 NG。保留命中词、原始来源及导入问题；空料号不会关联其他记录。
- 默认“高温贴纸”扩展为“贴纸”，覆盖普通贴纸；“碳带”覆盖树脂碳带，“锡膏”默认排除。升级旧默认词表时保留自定义词表和关闭选择，规则可继续编辑和重新核对。
- “检查更新”移至“设置 → 关于与更新”，顶部工具区简化。更新按操作系统和当前程序架构选择完整安装包；缺少对应架构时提供发布页面，避免下载错误二进制。
- 新增 Windows ARM64 Setup.exe、Linux ARM64 DEB 和 macOS Intel / Apple Silicon 通用 DMG，保留 Windows x64 和 Linux amd64 安装包。每个包提供 SHA256。
- Windows、Linux 分别在 x64 / ARM64 构建机上验证安装、启动和卸载；同一 macOS 通用 DMG 分别在 Apple Silicon 和 Intel 上验证。

Windows 10/11 x64；Windows 11 ARM64；Ubuntu 22.04+ / 兼容 Debian x64、ARM64（GTK 3 / glibc 2.35+）；macOS 12+ Intel、Apple Silicon。

下载对应架构的完整安装包，无需解压管理散文件。macOS 打开 DMG 后将 SMT-CHECK.app 拖到 Applications。
Windows 安装程序未代码签名；macOS 为临时签名，未进行 Developer ID 签名或公证，首次启动可能需要在系统“隐私与安全性”允许打开。
