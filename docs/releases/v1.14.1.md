# SMT Fusion 1.14.1

## 中文

- 坐标差异检测页改为清晰的导入与比较流程，空结果时不再显示无效筛选控件。
- CAD 坐标支持分别导出 TOP 与 BOT 文件，使用 `-TOP-CAD坐标.xlsx` 和 `-BOT-CAD坐标.xlsx` 后缀，并保留设备格式及导出回读检查。
- 设置中的更新入口调整到末尾，移除桌面图标刷新入口。
- 状态栏不再显示写死的旧版本号。

## English

- Clarified the coordinate comparison setup flow and removed empty filters before results exist.
- Added separate TOP and BOT CAD exports with `-TOP-CAD坐标.xlsx` and `-BOT-CAD坐标.xlsx` suffixes, preserving the existing device format and export readback checks.
- Moved About & Updates to the end of Settings and removed the desktop-icon refresh entry.
- Removed the hard-coded old version from the status bar.

## ภาษาไทย

- ปรับขั้นตอนเริ่มต้นของการเปรียบเทียบพิกัดให้ชัดเจน และซ่อนตัวกรองที่ยังใช้งานไม่ได้ก่อนมีผลลัพธ์
- เพิ่มการส่งออก CAD แยก TOP และ BOT โดยคงรูปแบบอุปกรณ์เดิมและการตรวจอ่านไฟล์หลังส่งออก
- ย้าย About & Updates ไปท้ายหน้าการตั้งค่า และนำรายการรีเฟรชไอคอนเดสก์ท็อปออก
- นำหมายเลขเวอร์ชันเก่าที่กำหนดตายตัวออกจากแถบสถานะ
