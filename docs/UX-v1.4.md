# SMT-CHECK 1.4 外观

默认浅色和黑色主题色，在设置中可选蓝色或绿色；选择自动保存。按钮、菜单选中、文字选择和输入焦点使用主题色，表格状态不随主题色改变。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 蓝色主题 | #1559BD | #8FBBFF |
| 绿色主题 | #087343 | #83DBAE |
| 一致行底色 | #BCE8CD | #12462E |
| 异常行底色 | #F8CBCF | #5A242B |
| 一致状态标记 | #086637，白字 | #086637，白字 |
| 异常状态标记 | #B21E2B，白字 | #B21E2B，白字 |

状态标记同时使用文字和图标。行文字和底色、状态标记文字和底色应达到至少 4.5:1 对比度；行底色与表格面板的区分度至少为 1.25:1。选中态另有加深底色，不覆盖红绿语义。

应用图标使用用户指定图稿，自身明暗和青蓝色效果保留；界面区域保持纯色，无 Material 3、紫色或渐变。
